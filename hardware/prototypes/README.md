# 硬件原型

这里放短期、可丢弃或可替换的实体原型记录。每个原型至少写明：

- 硬件版本 / 日期 / 参与人；
- 结构或接线改动；
- 限制条件（电源、限位、固定方式、急停）；
- 照片/视频和原始日志位置；
- 对应 Experiment / Decision；
- 已知失败和下一步。

原型记录不是最终规格。稳定结论应晋升到 `hardware/electronics/`、`hardware/mechanical/` 或对应的 Decision/Experiment。

> 任何实体动作前都必须满足机械固定、限位、6 V 限流、10 A 保险、人员净空和可立即断开 XT30 的条件。
