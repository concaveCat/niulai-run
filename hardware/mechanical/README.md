# 机械

保存 CAD、尺寸链、机构实验和版本化照片。当前**不冻结** 2DOF/3DOF、最终外形或具体材料。

约定：

- 短期、可丢弃或可替换的实体结构放到 [`../prototypes/`](../prototypes/)；
- 每个原型写明硬件版本、限制条件、照片/视频位置和对应 Experiment；
- 影响运动范围、力矩、限位或人身安全的改动必须标记 `HIGH RISK`；
- 机械固定、限位和急停条件不满足时，只能做 mock/CAD 检查，不能上电动作。

当前硬件基线见 [`../electronics/MODULAR_CARRIER_HARDWARE_SPEC_v0.2.md`](../electronics/MODULAR_CARRIER_HARDWARE_SPEC_v0.2.md)。
